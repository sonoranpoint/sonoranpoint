Security

Who has your tools, keys and equipment is your business. Here's how we keep it that way, in plain words.

Encrypted everywhere

Every page and every connection uses HTTPS: the website, the dashboard, and the stations talking to our servers. Browsers are told never to connect any other way.

Passwords are never stored as typed. Sign-in is handled by our login service, which keeps only a scrambled (hashed) copy, and you can sign in with an emailed link instead of a password.

Your data stays yours

Every company's equipment, people and history is walled off inside the database itself, not just hidden on screen. Each request is checked against who's signed in and which company they belong to, so one customer can never see another's data, even by changing a web address.

Who can do what

  • Four dashboard roles: View Only, Supervisor, Manager and Admin. People only get the buttons their role allows, and the database enforces the same rules.
  • By department: when your company is split into departments, sites or teams, everyone sees only the ones they're given (unless they're an admin over the whole company), and an admin or manager for one can only add or change people in their own. We set the split up for you, so nobody can widen their own access.
  • Every action has a name on it: each checkout, return, problem report and change is recorded with who and when.

Stations

  • One key per station. A station is set up with a one-time code that expires after 7 days. After that it uses its own key, which the server stores only in scrambled form.
  • Shut off from anywhere. A lost or stolen station can be disconnected from the dashboard in seconds. It stops working right away.
  • Admin menu needs a fob and a PIN. After 5 wrong PINs it locks for 15 minutes.
  • Lost badge? Replace it and the old one stops working immediately.
  • Offline doesn't mean open. A station that loses Wi-Fi keeps recording, and only for the badges and items it already knows.

Signed updates

Stations update themselves, and every update is digitally signed by Sonoran Point. A station checks the signature and the file before installing, and refuses anything that doesn't match, so nobody else can put their own software on your stations. If a new version doesn't start properly, the station goes back to the one before on its own.

Our team

Sonoran Point staff sign in with two-step sign-in: a password plus a code from an authenticator app. Access is limited to the people who set up and support your account, and what we change is logged.

Keys and passwords for our systems are kept in locked vaults, never in our code.

Where it runs

The dashboard and website run on Cloudflare. Your data is kept in a Postgres database run by Supabase, a managed database provider. Both handle physical security, hardware and network protection for us.

Report a problem

Think you've found a security issue? Email support@sonoranpoint.com with "Security" in the subject. We read every message and reply quickly. Questions about security for your company are welcome too: contact us.
